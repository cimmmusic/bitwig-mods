# Label Modulator

A modulator that's just text, for notes in a device's modulator area.

Step 1: rename any modulator (e.g. a Macro) to start with "Label" — "Label: Bass bus notes" — and its panel shows just the text ("Bass bus notes"), wrapped to the panel. Rename it to change the text.

Coming next: a "Label" entry in the modulator browser, and editing the text by double-clicking the panel.
