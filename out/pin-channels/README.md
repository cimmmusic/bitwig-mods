# Mixer: Pin Channels

Keep chosen channels in view while you scroll: handy for VCAs, buses or a reference track.

## Pinning

- Right-click a track (or several selected tracks) and choose Pin Channel. Unpin Channel takes it out again.
- Pins are remembered between sessions.

## Arranger

- Pinned tracks freeze like rows in a spreadsheet: a pinned track stays where it is until you scroll past it, then it sticks to the top edge while the other tracks scroll underneath.
- The whole row is frozen: track header, clip launcher and lanes. Several pinned tracks stack in their track order.
- Frozen rows work as normal: click, select, mute, solo and drag the volume.
