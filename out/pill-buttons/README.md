# Interface: Pill Buttons

Draws Bitwig's buttons, fields and other small rounded frames fully rounded: their ends are half circles, like pills. Groups of buttons that Bitwig joins together (segmented buttons) become one pill.

## Settings

In **Settings > Mods > Pill Buttons**:

- **Pill buttons**: on or off (applies at once).
- **No outlines on toolbar buttons**: the window toolbar's buttons (FILE, PLAY, play, stop, record...) draw no outline or dividers, just their icons and text. On by default.
- **Roundness (%)**: 100 is a full pill (ends are half circles); lower values give softer, rounded-rectangle corners. Default 80. Applies at once.
- **Up to height (px)**: frames up to this tall become pills; taller ones (panels) keep Bitwig's corners. Default 32.

Pairs with the **Minimal** theme, which gives buttons a single hairline outline and no background.
